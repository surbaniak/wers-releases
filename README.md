# Wers

Prosty, szybki czytnik Markdown dla macOS z możliwością tworzenia nowych dokumentów.

- Jasny, ciemny i szronowy motyw z natywnymi elementami macOS.
- Markdown, tabele, obrazy, kod, Mermaid i wzory matematyczne.
- Nowe dokumenty ze schowka i zapamiętywany folder zapisu.
- Ostatnio otwierane pliki i foldery.
- Podpisane aktualizacje przez Sparkle.

**Wymagania:** macOS 27 lub nowszy i Mac z Apple Silicon.

[Pobierz najnowsze wydanie](https://github.com/surbaniak/wers-releases/releases/latest)

Rozpakuj `Wers.zip`, przenieś `Wers.app` do Aplikacji i uruchom. Paczki wydań są podpisane Developer ID i notaryzowane przez Apple. Wersje 1.0.x wymagają jednorazowej instalacji wydania 1.1.0 lub nowszego, aby otrzymywać aktualizacje przez Sparkle.

To repozytorium zawiera gotowe wydania i kanał aktualizacji. Kod źródłowy aplikacji jest przechowywany osobno w repozytorium prywatnym.

Błędy można zgłaszać w [Issues](https://github.com/surbaniak/wers-releases/issues). Nie dołączaj prywatnych dokumentów ani danych poufnych do publicznych zgłoszeń.
